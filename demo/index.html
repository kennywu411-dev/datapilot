问“是多少”，也问“为什么变了”

MetricLens 用中文回答经营数据的问题。问一个数，它写 SQL 查出来；问一个指标为什么变了，它按国家、品类、客户、单据逐层拆开找原因，结论里的每个数字都能追溯到执行过的 SQL。下面 11 个问题各点一下，能按步骤看到全过程，每一步带当时的耗时和花费。

回放

这是真实运行记录的回放，不是在线服务。页面是纯静态的，不连后端、不调模型；SQL、结果、回答、耗时和花费都是录制时问数服务的原始输出，没有改写。想自己提问，按仓库 README 在本地启动。

    回放是怎么来的

    录的是问数服务本身

    录制脚本 scripts/record_replays.py 直接调用问数服务（和 /api/ask 同一段代码），逐事件记下到达时间，并记下每次模型调用的 token 和花费。原始记录在 demo/replays.json，页面只做展示。

    耗时和花费的口径

    每一步的耗时是这一步的事件比上一步晚到多少；花费按该次模型调用的 token 用量和价目表计算，合计与服务返回的总花费一致。通义千问的花费按标价估算。表结构随生成请求一起发送，不单独计时。归因里的分解、排序、下钻由 SQL 和代码完成，这几步花费是 0。

    数据范围

    归因的 3 个问题跑在 UCI Online Retail II 公开数据上（CC BY 4.0，客户编号已重新编号）；其中标了“注入”的那一个，是在库的副本里人为制造了一个已知原因再提问，页面上写明了注入的是什么。其余 8 个问题在模拟电商库上完成。结果表最多展示前 8 行。
