DataPilot 是一个中文问数（NL2SQL）系统。下面 8 个问题各点一下，就能按步骤看到一次问数从提问到出图的全过程，每一步都带当时的耗时和花费。

回放

这是真实运行记录的回放，不是在线服务。页面是纯静态的，不连后端、不调模型；SQL、结果、回答、耗时和花费都是录制时问数服务的原始输出，没有改写。想自己提问，按仓库 README 在本地启动。

    回放是怎么来的

    录的是问数服务本身

    录制脚本 scripts/record_replays.py 直接调用问数服务（和 /api/ask 同一段代码），逐事件记下到达时间，并记下每次模型调用的 token 和花费。原始记录在 demo/replays.json，页面只做展示。

    耗时和花费的口径

    每一步的耗时是这一步的事件比上一步晚到多少；花费按该次模型调用的 token 用量和价目表计算，合计与服务返回的总花费一致。通义千问的花费按标价估算。表结构随生成请求一起发送，不单独计时。

    数据范围

    8 个问题、15 次提问全部在模拟电商库上完成，数据由固定种子脚本生成，不含真实用户信息，也不含 BIRD 的数据库内容。结果表最多展示前 8 行。
