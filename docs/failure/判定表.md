# 50 道失败题判定表

来源：Sonnet 最终配置 E4（`e4-3463b8`）的 140 道失败题中，按难度分层、固定种子（seed=0）随机抽 50 道。数据：`docs/failure/sample50.json`。

## 判定标准（先定标准再判）

| 类别 | 含义 | 判定依据 |
|---|---|---|
| A 模型错 | 题目、evidence、标准答案都清楚，模型 SQL 语义错 | 能指出模型 SQL 的具体错误 |
| B 标准答案错 | 标准 SQL 与题目或 evidence 不符 | 能指出标准 SQL 违背了题目/evidence 的哪一处 |
| C 题目歧义 | 题目有两种以上合理理解，模型和标准答案各取一种 | 两种理解都说得通（含多返回/少返回列、并列处理） |
| D 评测缺陷 | 语义等价但 EX 判错 | 结果意思相同，只差表示方式、类型、超时口径 |
| E 两者都错 | 两边都有语义错误 | |
| F 系统故障 | 没有产出 SQL 等运行问题 | |

## 判定结果（预分类后逐题人工复核，全部同意）
